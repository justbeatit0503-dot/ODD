# 원형적 렌즈(Archetypal Lens) 카탈로그

렌즈는 대상을 비추는 '깊은 서사 구조'다. 좋은 렌즈는 대상과 표면적으로 멀되, 어느 위계에서
구조적으로 동일한 문제를 풀고 있다. 아래는 대표 렌즈와 그 조명 포인트, 매핑 요령이다.

## 1. 성경 / 신화 (Bible / Myth)
- **핵심 구조:** 두 힘의 전쟁(신 vs 신, 질서 vs 혼돈)으로 세상사를 읽는다.
- **잘 맞는 대상:** 유한한 자원(경배·관심·충성·시장점유)을 둘러싼 다툼. 플랫폼, 종교, 이념, 브랜드.
- **매핑 요령:**
  - L0 = 마음에 새긴 율법 / 내재화된 신성 (외부 강제가 불필요해지는 융합)
  - L1 = 창조 질서·언약 구조 (중력장)
  - L2 = 응보 vs 교화, 자유 vs 통제 (트레이드오프)
  - L3 = 율법 조항·성전·제사 (물리적 닻)
  - 전쟁 = 유한한 경배를 둘러싼 신들의 다툼
  - 우상 = 값싸게 양산되는 경쟁 대안 / 제사장 = 경배를 분배하는 게이트키퍼(알고리즘 등)
- **적용할 대표 사건:** 창조(런칭), 에덴(닫힌 정원), 타락(탈옥), 바벨(프로토콜 파편화),
  출애굽(유저 대이동), 성육신·오순절(내재화·프로토콜 복원).

## 2. 열역학 / 엔트로피 (Thermodynamics)
- **핵심 구조:** 모든 시스템은 무질서(엔트로피)로 향하고, 질서는 에너지 투입으로만 국소적으로 유지된다.
- **잘 맞는 대상:** 조직, 코드베이스, 시장, 습관, 관계 등 "가만두면 무너지는" 모든 것.
- **매핑 요령:** L0 = 엔트로피에 맞선 존재 이유 / L3 = 질서 유지에 드는 실제 에너지(운영·노동).
  핵심 질문: "이 시스템의 질서를 유지하는 에너지원은 무엇이고, 끊기면 어떻게 붕괴하는가?"

## 3. 진화 / 생태계 (Evolution / Ecosystem)
- **핵심 구조:** 변이·선택·적응, 틈새(niche) 점유, 경쟁과 공생, 군비경쟁.
- **잘 맞는 대상:** 제품 경쟁, 콘텐츠 생태계, 기술 표준, 문화 밈.
- **매핑 요령:** L1 = 생태적 지위 구조 / L2 = 특화 vs 범용의 트레이드오프 / L3 = 개별 개체(제품·종).
  핵심 질문: "이것은 어떤 틈새를 점유했고, 포식자·경쟁자·공생자는 누구인가?"

## 4. 면역계 / 유기체 (Immune System / Organism)
- **핵심 구조:** 자기/비자기 구분, 경계 방어, 침입과 항체, 자가면역(과잉방어)의 역설.
- **잘 맞는 대상:** 보안, 조직 문화, 국경·이민, 커뮤니티 모더레이션, 콘텐츠 검열.
- **매핑 요령:** L0 = 자기 정체성의 보존 / L2 = 개방(감염 위험) vs 폐쇄(경직) 트레이드오프.
  핵심 질문: "무엇을 자기로 보고 무엇을 배척하는가? 과잉방어가 자신을 해치지 않는가?"

## 5. 전쟁사 / 제국 (War / Empire)
- **핵심 구조:** 영토 확장, 보급선, 동맹과 배신, 해자(moat), 제국의 과잉확장과 붕괴.
- **잘 맞는 대상:** 시장 점유 경쟁, 플랫폼 패권, 지정학, 커리어 전략.
- **매핑 요령:** L1 = 전략 지형 / L2 = 집중 vs 분산의 트레이드오프 / L3 = 개별 전투·전술.
  핵심 질문: "해자는 무엇이고, 보급선(현금흐름·인력)은 어디서 끊길 수 있는가?"

## 6. 연금술 / 변성 (Alchemy / Transformation)
- **핵심 구조:** 비천한 재료(납)를 귀한 것(금)으로 변성. 용해와 응고(solve et coagula).
- **잘 맞는 대상:** 학습·성장, 예술 창작, 데이터→통찰, 원료→제품 가치사슬.
- **매핑 요령:** L0 = 변성의 궁극(주체 자신의 변화) / L3 = 실제 변환 공정.

## 렌즈 선택 알고리즘
1. 대상의 **가장 치열한 L2 트레이드오프**가 무엇인지 먼저 찾는다.
2. 그 트레이드오프와 같은 긴장을 가진 렌즈를 고른다.
   (예: 유한 자원 다툼 → 성경/전쟁, 개방 vs 폐쇄 → 면역계, 붕괴 압력 → 열역학)
3. 두 렌즈가 팽팽하면 **둘 다** 써서 교차 매핑을 두 번 하고, 더 조명력 있는 쪽을 본문으로 삼는다.
4. 매핑이 3개 이상의 위계에서 자연스럽게 맞물리면 그 렌즈는 유효하다. 한두 개만 맞으면 장식이니 버린다.
