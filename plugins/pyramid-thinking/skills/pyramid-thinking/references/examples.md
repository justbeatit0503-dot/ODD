# 분해 예시 (pyramid-lens에서 필요할 때만 읽는다)

대상의 본질을 네 층으로 분해한 예다. 형식 참고용이며, 새 대상에는 같은 구조를 새로 세운다. 계획·결정 답변에서는 이 라벨 형식을 쓰지 않는다. 예시는 분해(절차 1)만 보인다. 실제 답에는 층마다 검증도와 맞지 않는 곳을 붙인다.


### ⚖️ 예시 1: 사회 질서와 법 (Jurisprudence)

* **[L0] 존재론:** 죄의 근절과 도덕률의 체화.
  * *심화 해석:* 법의 궁극적 목표는 '법전'이라는 외부 강제 수단이 필요 없는 상태다. 법이 사라진 무법천지(**해체**)와 겉모습은 같지만, 모든 인간의 내면에 법이 자리 잡아 외부 강제가 불필요해지는 **체화**의 단계다. 둘은 사회가 계속 작동하는지로 구분된다.
* **[L1] 추상/구조:** 헌법적 가치, 삼권 분립(견제와 균형), 사회 계약론.
* **[L2] 선택/조정:** '응보(처벌)'와 '교화(회복)' 사이의 형량 조절. 개인의 자유와 공공의 안전 사이의 첨예한 트레이드오프.
* **[L3] 실행/인스턴스:** 형법 제250조, 경찰의 체포 매뉴얼, 수갑, 교도소. (강제력을 지닌 이 실행 층이 현실에서 작동하지 않으면 L0의 이상은 즉시 무너진다.)

### 🧠 예시 2: 인공지능과 지식 시스템 (AI · Cognitive Systems)

* **[L0] 존재론:** 인류 인지 능력의 확장과 정보 격차의 해소.
  * *심화 해석:* AI의 종착지는 '프롬프트를 입력하는 행위'가 별도의 절차로 느껴지지 않을 만큼 사고에 **체화**되는 것이다. 인간의 의도와 기계의 연산이 이어져, 묻기 전에 통찰이 직관처럼 떠오르는 상태다.
* **[L1] 추상/구조:** 트랜스포머 아키텍처, 지식 그래프(Knowledge Graph), 확률 기반의 언어 모델 설계.
* **[L2] 선택/조정:** 환각(Hallucination) 억제와 응답의 다양성·창의성 사이의 균형(예: 샘플링 temperature 조절). 자원 효율과 추론 깊이 사이의 조정.
* **[L3] 실행/인스턴스:** Python 스크립트, Vector DB 인덱싱, GPU 클러스터, API 호출. (이 고된 엔지니어링 작업 없이는 어떤 인지적 확장도 불가능하다.)

### 💰 예시 3: 자본과 가치 교환 (Economics)

* **[L0] 존재론:** 결핍의 극복과 시간(생존)의 자유 획득.
  * *심화 해석:* 자본 증식의 진짜 목적은 통장 잔고의 숫자가 아니라, 역설적으로 **돈에 대한 의식 자체가 체화되어 사라지는 것**이다. 자원이 숨 쉬듯 순환해 결핍을 느끼지 않고, 자기가 하려는 일에 시간을 온전히 쓸 수 있는 상태다.
* **[L1] 추상/구조:** 수요와 공급의 법칙, 신용 창조, 화폐 시스템.
* **[L2] 선택/조정:** 인플레이션에 의한 가치 하락 방어(위험 감수)와 원금 보존(안정성) 사이의 자산 배분 비율 조정.
* **[L3] 실행/인스턴스:** S&P 500 ETF 매수, 달러 환전, 주식 거래 앱의 매매 버튼 클릭.

## 간단한 예시

### 비즈니스 마케팅 (Marketing)

* **L0 (존재론/목적):** 고객이 겪는 문제의 해결을 통한 가치 교환과 신뢰 구축.
* **L1 (구조):** 인지-고려-전환-유지로 이어지는 고객 여정(Funnel) 설계.
* **L2 (선택/조정):** 단기 매출보다 브랜드 자산 형성을 위해 퍼포먼스 광고 예산을 줄이고 콘텐츠 마케팅 비중을 높임. (포기하는 것: 단기 전환율)
* **L3 (실행):** 인스타그램 카드뉴스 제작, 리타겟팅 픽셀 설치, 주간 ROAS 리포트.
